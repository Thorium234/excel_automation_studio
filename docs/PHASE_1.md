# Excel Automation Studio

Excel Automation Studio is a Java 21 and JavaFX desktop application for generating, executing and validating spreadsheet practice exercises.

## Requirements

- JDK 21
- Apache Maven 3.9 or newer

## Build

```bash
mvn clean package
```

## Run

```bash
mvn javafx:run
```

## Phase 1 status

The project foundation includes a JavaFX Maven application, dashboard navigation, application CSS, SLF4J/Logback logging, and JUnit 5 test support.
